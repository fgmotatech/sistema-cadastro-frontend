Política de Privacidade

Última atualização: 24 de julho de 2026
🔒 Este sistema é um projeto de demonstração desenvolvido para fins de portfólio. Os dados cadastrados são removidos automaticamente após 24 horas.

1. Sobre esta Política

Esta Política de Privacidade explica como as informações fornecidas pelos usuários são coletadas, utilizadas e armazenadas neste sistema.

O objetivo é garantir transparência sobre o tratamento dos dados durante o uso da aplicação.

2. Dados coletados

Durante o cadastro, podemos coletar as seguintes informações:

  • Nome completo;
  • Número de telefone;
  • E-mail;
  • Senha de acesso.

Recomendamos que o usuário não informe dados pessoais sensíveis durante os testes.

3. Uso das informações

Os dados coletados são utilizados exclusivamente para:

  • Criação de uma conta;
  • Teste das funcionalidades de cadastro e login;
  • Demonstração do funcionamento do sistema.

As informações não são vendidas, compartilhadas ou utilizadas para fins comerciais.

4. Armazenamento dos dados

Este sistema possui finalidade exclusivamente demonstrativa. Os dados cadastrados permanecem armazenados temporariamente por até 24 horas.

Após esse período, os registros são removidos automaticamente.

5. Segurança das informações

São utilizadas boas práticas de desenvolvimento para proteção dos dados, incluindo:

  • Proteção de senhas utilizando criptografia;
  • Controle de acesso ao banco de dados;
  • Uso de conexões seguras quando disponíveis.

6. Exclusão dos dados

O usuário entende que, por se tratar de um ambiente de demonstração, todas as contas criadas podem ser excluídas automaticamente após o período definido de armazenamento.

7. Cookies e armazenamento local

O sistema pode utilizar recursos técnicos necessários para funcionamento, como armazenamento de sessão e preferências temporárias.

8. Alterações nesta política

Esta política poderá ser atualizada conforme novas funcionalidades forem adicionadas ao sistema.

9. Contato

Para dúvidas ou solicitações relacionadas aos dados, utilize o canal de contato disponibilizado no projeto.

Sistema desenvolvido para fins educacionais e apresentação de portfólio.
